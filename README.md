# Austin TV — World Foundation

Bilingual React + Vite visual prototype for Austin TV (Mexico City).

## Run
```bash
npm install
npm run dev
npm run build
```

## Status
**Prototype, not a verified production app.** The hero uses CSS artwork because licensed band photography and custom font files were not available. The sound lab plays original synthesized demo tones, not Austin TV recordings. Merch checkout, uploads, downloads and AI inference are intentionally not active until permissions, backend and payment credentials are verified. No unconfirmed concerts are listed.

## Vercel
Import this repository, framework Vite, build `npm run build`, output `dist`. SPA rewrite is in `vercel.json`.
